Guía 01

Crear una cuenta

crear una cuenta para guardar y compartir diagramas.

Pasos 1–5

  1. Abra la aplicación.
  2. En la pantalla Inicia sesión, presione Crea una.
  3. Complete Nombre, Correo, Contraseña y Repite la contraseña.
  4. La contraseña debe tener al menos 8 caracteres.
  5. Presione Crear cuenta.
✓ Resultado esperado

la cuenta se crea, la sesión se inicia automáticamente y se muestra la pantalla de proyectos.

i Nota

si el correo ya está registrado, el formulario lo indicará junto al campo Correo.

Guía 02

Iniciar sesión

ingresar a los proyectos de una cuenta existente.

Pasos 1–3

  1. Abra la aplicación.
  2. Escriba su Correo y Contraseña.
  3. Presione Entrar.
✓ Resultado esperado

se muestra la pantalla principal con los proyectos propios y los proyectos compartidos.

Guía 03

Conocer la pantalla principal

La pantalla principal muestra el nombre de la persona conectada y su UUID, que es el identificador utilizado para recibir invitaciones.

Los proyectos se separan en dos grupos:

  • Mis proyectos: proyectos creados por la persona conectada.
  • Proyectos invitados: proyectos de otras personas a los que se obtuvo acceso al aceptar una invitación. Estas tarjetas llevan la indicación Compartido y muestran el nombre del dueño.

Las acciones visibles son:

  • Copiar: copia el UUID propio.
  • Importar boceto: inicia la reconstrucción de un diagrama desde una imagen.
  • Nuevo proyecto: crea un proyecto vacío.
  • Invitaciones: muestra las invitaciones recibidas.
  • Cerrar sesión: finaliza la sesión.
Cerrar sesión

Cerrar sesión

finalizar la sesión actual.

Pasos 1–2

  1. Regrese a la pantalla de proyectos.
  2. Presione Cerrar sesión en la parte superior derecha.
✓ Resultado esperado

la aplicación vuelve a la pantalla Inicia sesión.

Antes de comenzar: propósito, usuarios y requisitos

Acerca de este manual

Este manual explica cómo utilizar la aplicación Diagramador UML desde el registro de una cuenta hasta la creación, colaboración, importación, exportación y recuperación de diagramas. Está dirigido a personas usuarias; no requiere conocimientos de programación ni explica la construcción interna del sistema.

La aplicación

Diagramador UML permite crear diagramas de clases en un lienzo visual. Una persona puede crear clases e interfaces, añadir atributos y operaciones, relacionar los elementos, trabajar al mismo tiempo con otras personas y conservar el diagrama en línea.

La aplicación también permite:

  • importar y exportar diagramas en JSON y XMI;
  • reconstruir un diagrama a partir de una imagen o fotografía;
  • conversar con una IA por texto o voz;
  • solicitar a la IA cambios que el equipo confirma mediante votación;
  • guardar y restaurar versiones;
  • generar un backend Spring Boot descargable.

Usuarios del sistema

Todas las personas utilizan una cuenta registrada. Según el proyecto abierto, la misma persona puede actuar como:

  • Dueño del proyecto: creó el proyecto, puede editarlo e invitar a otras personas.
  • Colaborador: aceptó una invitación y puede abrir y editar el proyecto compartido. No puede invitar a otras personas desde ese proyecto.

No existe una pantalla separada para administrar roles.

Requisitos

Para utilizar la aplicación se necesita:

  • un navegador web moderno;
  • conexión a Internet;
  • una cuenta en la aplicación;
  • permiso para usar el micrófono cuando se utilicen notas de voz o el agente virtual;
  • acceso a descargas del navegador para exportar JSON, XMI o el backend Spring Boot.

Las funciones de boceto, chat con IA, voz y agente virtual también dependen de que el servicio de IA se encuentre disponible.

Abrir un proyecto propio o compartido

03

Editor UML

Pase de un lienzo vacío a un diagrama de clases completo.

Guía 07

Conocer el editor

El editor está formado por:

  • una barra superior con Proyectos, nombre del modelo, Deshacer, Rehacer, importaciones, exportaciones, estado de guardado, participantes, Exportar backend e Invitar;
  • el panel izquierdo Clases, que contiene la paleta de elementos;
  • el lienzo central, con controles de zoom y minimapa;
  • el panel derecho, con las pestañas Propiedades, Chat y Versiones.

Los paneles laterales se pueden ocultar y volver a mostrar con sus botones de plegado.

El estado de guardado puede mostrar Cambios sin guardar, Guardando…, Guardado o No se pudo guardar.

Crear una clase o interfaz

añadir un clasificador al diagrama.

Pasos 1–3

  1. En el panel Clases, localice Clase, Clase abstracta o Interfaz.
  2. Utilice una de estas formas:
    • arrastre el elemento hasta el lugar deseado del lienzo; o
    • presione el elemento y luego presione el lugar del lienzo donde desea crearlo.
  3. Para volver al modo normal, presione Seleccionar o la tecla Esc.
✓ Resultado esperado

aparece una nueva caja UML en el lienzo.

Configurar sus propiedades

cambiar los datos generales de una clase o interfaz.

Pasos 1–4

  1. Seleccione la caja.
  2. Abra la pestaña Propiedades.
  3. Modifique Nombre, Visibilidad o Estereotipos.
  4. En una clase, active Clase abstracta cuando corresponda.
✓ Resultado esperado

el elemento se actualiza en el lienzo.

i Nota

también puede hacer doble clic en el nombre mostrado dentro de la caja para editarlo.

Mover, eliminar, deshacer y cambiar el nombre del modelo

Mover, redimensionar y acomodar elementos

ordenar visualmente el diagrama.

Pasos 1–5

  1. Active Seleccionar.
  2. Arrastre una clase para moverla.
  3. Utilice los controles de tamaño de la caja para redimensionarla.
  4. Con una relación seleccionada, arrastre los puntos de la línea para doblarla.
  5. Si una relación tiene puntos manuales, presione Enderezar para quitarlos.
✓ Resultado esperado

el diagrama adopta la nueva distribución.

Atajos útiles:

  • flechas: mover la selección 1 unidad;
  • Mayús + flechas: mover 10 unidades;
  • Ctrl + A: seleccionar todo;
  • Ctrl + 0: ajustar todo el diagrama a la vista.

Eliminar elementos

quitar clases o relaciones seleccionadas.

Pasos 1–3

  1. Active Seleccionar.
  2. Seleccione uno o varios elementos.
  3. Presione Supr o Retroceso.
✓ Resultado esperado

los elementos desaparecen del diagrama.

! Advertencia

al eliminar una clase también pueden desaparecer sus relaciones. Si fue un error, utilice Deshacer inmediatamente.

Deshacer y rehacer

revertir o recuperar cambios locales del editor.

Pasos 1–2

  1. Presione Deshacer o use Ctrl + Z.
  2. Presione Rehacer, Ctrl + Mayús + Z o Ctrl + Y para recuperar el cambio.
✓ Resultado esperado

el diagrama vuelve al estado anterior o posterior correspondiente.

i Nota

el historial de deshacer corresponde a sus acciones locales; no deshace una acción remota de otra persona.

Cambiar el nombre del modelo

cambiar el nombre interno del diagrama abierto.

Pasos 1–2

  1. En la barra superior, edite el campo Nombre del modelo situado junto a Diagramador UML.
  2. Haga clic fuera del campo para finalizar la edición.
✓ Resultado esperado

el modelo adopta el nuevo nombre y se guarda con el diagrama.

i Nota

esta acción no cambia el nombre de la tarjeta del proyecto en la pantalla principal.

Guía 08

Crear atributos y operaciones

Agregar un atributo

añadir una propiedad a una clase.

Pasos 1–6

  1. Seleccione la clase.
  2. En Propiedades, ubique Atributos.
  3. Presione + agregar.
  4. Complete Nombre, Tipo y Visibilidad.
  5. Active {id} si el atributo identifica a la clase y debe utilizarse como clave primaria al exportar el backend.
  6. Abra Más opciones si necesita multiplicidad, valor por defecto o modificadores como static, derivado, readOnly, ordered o unique.
✓ Resultado esperado

el atributo aparece en el compartimento de atributos de la clase.

i Alternativa

arrastre Atributo desde la paleta hasta una clase, o seleccione Atributo y luego presione la clase.

Agregar una operación

añadir una operación o método UML.

Pasos 1–6

  1. Seleccione la clase o interfaz.
  2. En Propiedades, ubique Operaciones.
  3. Presione + agregar.
  4. Complete Nombre, Retorno y Visibilidad.
  5. Para añadir argumentos, presione + parámetro y configure su nombre, tipo, dirección y valor por defecto.
  6. En Más opciones, active static, abstracta o query si corresponde.
✓ Resultado esperado

la operación aparece en el compartimento de operaciones.

i Alternativa

arrastre Operación desde la paleta hasta una clase, o selecciónela y luego presione la clase.

Reordenar o eliminar miembros y parámetros

Reordenar o eliminar atributos, operaciones y parámetros

organizar o quitar miembros de una clase.

Pasos 1–4

  1. Seleccione la clase y abra el miembro en Propiedades.
  2. Use ↑ o ↓ para cambiar el orden de un atributo u operación.
  3. Presione ✕, cuyo nombre accesible es Eliminar, para quitarlo.
  4. En un parámetro, presione ✕, cuyo nombre accesible es Quitar parámetro.
✓ Resultado esperado

la lista y la caja UML se actualizan.

Guía 09

Crear relaciones y multiplicidades

Crear una relación

unir dos clasificadores mediante una relación UML.

Relaciones disponibles:

  • Asociación;
  • Asociación dirigida;
  • Agregación;
  • Composición;
  • Generalización;
  • Realización;
  • Clase de asociación.

Pasos 1–3

  1. En Relaciones, seleccione el tipo deseado.
  2. Arrastre desde una clase hasta la otra; también puede presionar primero la clase de origen y luego la de destino.
  3. Presione Esc al terminar para volver a Seleccionar.
✓ Resultado esperado

se dibuja la relación. Si la combinación no es válida, aparece un aviso sobre el lienzo.

i Nota

al crear una Clase de asociación, el editor crea la relación y también una caja asociada, con multiplicidades 0..* en ambos extremos de forma inicial.

Configurar una relación y sus multiplicidades

definir el significado y la presentación de una relación.

Pasos 1–5

  1. Seleccione la línea de la relación.
  2. En Propiedades, configure el Nombre y la Lectura cuando estén disponibles.
  3. Elija el Trazado: Recta, Ortogonal o Curva.
  4. En Origen y Destino, complete Rol y Multiplicidad.
  5. Configure Visibilidad, Navegable, ordered y unique cuando corresponda.
✓ Resultado esperado

las etiquetas, multiplicidades y forma de la línea se actualizan.

i Nota

las relaciones de generalización y realización no muestran campos que no correspondan a su notación.

saber quién se encuentra en el proyecto y qué está haciendo.

  2. Revise el nombre y estado de cada participante.

  • Editando;
  • Escribiendo…;
  • Grabando…;
  • Inactivo;
  • Desconectado.
✓ Resultado esperado

se muestra la lista de personas presentes. Cada una conserva un color estable en cursores y selecciones.

Seguir la ubicación de otra persona

centrar la vista en el trabajo de otro participante.

Pasos 1–2

  1. Abra la lista de participantes.
  2. Presione el nombre de otra persona.
✓ Resultado esperado

la vista se centra en su cursor o, si no está sobre el lienzo, en los elementos que tenga seleccionados.

i Nota

si la persona no tiene cursor ni selección visible, la aplicación muestra un aviso.

Reconexión

Si se interrumpe la conexión, la barra superior muestra Reconectando…. Puede continuar editando: la aplicación conserva una cola de cambios y trata de enviarlos cuando vuelve la conexión.

Si durante la desconexión se reemplaza el diagrama completo —por ejemplo, mediante una importación—, al reconectar esa copia puede reemplazar la de la sala y la aplicación lo avisa.

Importar y exportar

Guía 11

Importar y exportar JSON/XMI

Identifique los cuatro controles de intercambio en la barra del editor. Cada imagen se utiliza una sola vez; los pasos siguientes comparten esta referencia.

Exportar XMI

descargar el diagrama en XMI 2.1, utilizable en herramientas como Enterprise Architect.

Pasos 1–3

  1. Abra el proyecto.
  2. Presione Exportar XMI en la barra superior.
  3. Guarde el archivo cuando el navegador lo solicite.
✓ Resultado esperado

se descarga un archivo .xmi con el modelo.

Importar XMI

reemplazar el diagrama abierto con un modelo contenido en un archivo XMI.

Pasos 1–4

  1. Abra el proyecto que recibirá el contenido.
  2. Presione Importar XMI.
  3. Seleccione un archivo .xmi o .xml.
  4. Revise el aviso que aparece sobre el lienzo.
✓ Resultado esperado

las clases, interfaces, miembros y relaciones reconocidos reemplazan el diagrama del proyecto y quedan pendientes de guardado.

i Nota

el importador reconoce XMI 2.1 y archivos XMI 1.x de Enterprise Architect. Si el archivo contiene elementos no soportados, se importa lo reconocido y el aviso indica las omisiones. Cuando no hay posiciones utilizables, las cajas se distribuyen automáticamente.

! Advertencia

la importación reemplaza el contenido actual del editor. Guarde una versión antes si necesita volver con facilidad.

Errores posibles:

  • el archivo no es XML válido;
  • el archivo está vacío;
  • no se encuentra ninguna clase o interfaz;
  • alguna información del archivo no está soportada y se omite.

Exportar JSON

guardar una copia en el formato propio del diagramador.

Pasos 1–2

  1. Presione Exportar JSON.
  2. Guarde el archivo .uml.json.
✓ Resultado esperado

se descarga una copia completa del diagrama.

Importar JSON

cargar una copia creada por el diagramador.

Pasos 1–3

  1. Presione Importar JSON.
  2. Seleccione el archivo .uml.json o .json.
  3. Revise el mensaje mostrado sobre el lienzo.
✓ Resultado esperado

el documento válido reemplaza el diagrama actual y se guarda posteriormente en el proyecto.

! Advertencia

la importación reemplaza el contenido actual del editor.

Guía 12

Seleccionar y procesar un boceto

reconstruir un diagrama a partir de una foto o captura.

la interpretación puede confundir nombres, posiciones, tipos de relación o multiplicidades. Revise siempre el resultado antes de continuar el modelado.

07

Generar Spring Boot

Prepare las claves de sus clases y descargue el backend.

Guía 13

Generar el backend Spring Boot

Antes de exportar

Para exportar, el diagrama debe contener al menos una clase. Cada clase normal debe tener exactamente un atributo marcado como {id}. Las subclases heredan la clave de la raíz de su jerarquía. Una clase de asociación utiliza una clave compuesta basada en sus extremos y no necesita elegir una clave propia.

descargar un proyecto Spring Boot generado desde el diagrama.

Pasos 1–6

  1. Abra el proyecto y espere a que los cambios estén guardados.
  2. Presione Exportar backend.
  3. En Exportar backend, revise las clases y los tipos de sus atributos.
  4. Para cada clase que lo requiera, seleccione un atributo en la columna clave.
  5. Corrija las filas que indiquen Ninguna propiedad marcada como clave o varias claves.
  6. Presione Exportar.
✓ Resultado esperado

el navegador descarga un archivo .zip con el proyecto generado.

El archivo incluye la aplicación Spring Boot, entidades, DTO, mapeadores, repositorios, servicios y controladores para las clases concretas, documentación Swagger/OpenAPI, configuración y una colección de Postman. Las clases abstractas e interfaces se representan en el código, pero no generan un CRUD propio.

i Nota

antes de exportar, la aplicación guarda lo que está en pantalla porque el servidor genera el archivo desde el contenido guardado.

08

Agente virtual

Consulte y edite el diagrama mediante una conversación de voz.

Guía 14

Hablar con el agente virtual

consultar o modificar el diagrama mediante órdenes habladas.

Pasos 1–6

  1. Abra la pestaña Propiedades.
  2. Presione Hablar con el agente.
  3. Cuando el navegador solicite acceso, conceda permiso al micrófono.
  4. Espere el indicador Te escucho.
  5. Hable de forma breve y mencione los nombres de los elementos.
  6. Presione Colgar al terminar.
✓ Resultado esperado

el agente responde por voz, muestra la transcripción del diálogo y aplica las operaciones solicitadas cuando son válidas.

Puede usar Silenciar y volver a activar el micrófono durante la llamada.

Operaciones disponibles

El agente puede:

  • resumir el diagrama y describir una clase;
  • crear, renombrar, mover o eliminar clases;
  • agregar, modificar o quitar atributos;
  • agregar o quitar operaciones;
  • crear, modificar o eliminar relaciones;
  • ordenar el diagrama;
  • cambiar el trazado o enderezar una relación;
  • deshacer la última acción local.

Ejemplos respaldados por la interfaz:

  • “Agregá un atributo precio a Película”.
  • “¿Qué relaciones tiene Socio?”.
  • “Poné NotaAlquiler a la derecha de Ejemplar”.
  • “Ordená el diagrama”.

Confirmaciones y nombres ambiguos

Antes de eliminar una clase o relación, el agente debe pedir una confirmación explícita. La eliminación no se ejecuta si no recibe esa confirmación.

Si varios elementos tienen nombres parecidos, el agente debe pedir que indique cuál. Si no entiende un nombre, repítalo con más claridad o seleccione y edite el elemento manualmente.

Problemas del agente

Si aparece un mensaje sobre el micrófono, revise el permiso del navegador. Si la llamada muestra Se cortó la llamada o informa que no pudo contactar con la IA, cuelgue y vuelva a intentarlo cuando la conexión o el servicio estén disponibles.

Guía 17

Votar los cambios de la IA

Cuando una solicitud del chat modifica el diagrama, el cambio se aplica de forma provisional y se marca en el lienzo hasta que la sala decida.

conservar o descartar como equipo los cambios de la IA.

Pasos 1–4

  1. Revise el panel Cambios de la IA sobre el cuadro de mensaje.
  2. Examine la lista de cambios y el tiempo restante.
  3. Presione Conservar o Descartar.
  4. Si lo desea, cambie su voto antes del cierre.
✓ Resultado esperado

al cerrar la votación, la aplicación indica si los cambios se conservan o se descartan. Si se descartan, se revierte el cambio; si se conservan, se crea una versión de origen IA.

También se reconocen respuestas breves como “sí” o “no” en el chat y en notas de voz. La votación cierra cuando votaron todas las personas presentes o al llegar al límite de dos minutos. En empate, decide el voto de quien pidió el cambio. La regla del caso de uso establece que, si nadie vota antes de finalizar la votación, los cambios se conservan porque ya fueron aplicados al diagrama.

! Función parcialmente implementada

Según el checklist existente, la regla de conservar los cambios cuando nadie vota todavía está pendiente: la versión revisada los descarta. Para decidir el resultado, emita un voto explícito con Conservar o Descartar.

Solución de problemas

Encuentre una causa posible y una acción concreta para continuar.

No se puede iniciar sesión

Posible causa
Correo o contraseña incorrectos; cuenta desactivada; conexión interrumpida
Solución
Revise los datos. Si aparece Credenciales invalidas, vuelva a escribirlos. Compruebe la conexión y reintente.

No se cargan los proyectos

Posible causa
El servidor o la conexión no están disponibles
Solución
Presione Reintentar.

No se puede abrir un proyecto

Posible causa
El proyecto no existe, no tiene permisos o el contenido no es válido
Solución
Regrese con Volver a mis proyectos. Compruebe que la invitación esté aceptada y pida al dueño que confirme el acceso.

No aparece un proyecto invitado

Posible causa
La invitación sigue pendiente o la lista no se actualizó
Solución
Abra Invitaciones, presione Aceptar y, si hace falta, Actualizar.

No se puede invitar

Posible causa
No es el dueño, el UUID no es válido, no existe el usuario o ya fue invitado
Solución
Use un proyecto propio y copie exactamente el UUID de la otra persona.

Aparece Reconectando…

Posible causa
Se interrumpió el socket de la sala
Solución
Continúe con precaución y espere la reconexión. Revise después el aviso de sincronización y el estado de guardado.

Aparece No se pudo guardar

Posible causa
Falló la conexión o el servidor rechazó el guardado
Solución
Mantenga el editor abierto, recupere la conexión y realice otro cambio o vuelva a la lista para provocar un nuevo intento de guardado.

XMI no se importa

Posible causa
El archivo no es XML válido, está vacío o no contiene clases/interfaz reconocibles
Solución
Exporte nuevamente desde la herramienta de origen como XMI 1.x o 2.1 y revise el archivo.

Faltan elementos después de importar XMI

Posible causa
El archivo contiene elementos no soportados
Solución
Revise el aviso mostrado y complete manualmente lo omitido.

El boceto no se reconoce

Posible causa
Imagen borrosa, inclinada, demasiado grande o IA no disponible
Solución
Use una foto nítida y frontal en PNG, JPG o WebP de hasta 10 MB y vuelva a intentar.

El micrófono no funciona

Posible causa
Permiso bloqueado o dispositivo no disponible
Solución
Permita el micrófono para el sitio y compruebe el dispositivo seleccionado por el navegador.

Una nota queda Sin transcripción

Posible causa
No se entendió el audio o falló el servicio
Solución
Reproduzca la nota y vuelva a grabarla con menos ruido.

La IA no responde

Posible causa
Servicio de IA no configurado, no disponible o tiempo de espera agotado
Solución
Reintente más tarde. El resto del editor puede seguir utilizándose.

No se puede exportar Spring Boot

Posible causa
No hay clases o alguna clase no tiene exactamente una clave
Solución
Agregue un atributo, marque {id} o elija la clave en Exportar backend.

No se puede restaurar una versión

Posible causa
Hay una votación abierta o la versión no se pudo cargar
Solución
Espere el cierre de la votación y vuelva a intentar.

Preguntas frecuentes

¿Cómo creo un proyecto?

En Mis proyectos, presione Nuevo proyecto, escriba el nombre y elija Crear y abrir.

¿Cómo invito a otra persona?

Pídale su UUID, abra un proyecto propio, presione Invitar, busque el UUID y confirme con Invitar.

¿Puedo trabajar con otra persona al mismo tiempo?

Sí. Cuando ambas personas abren el proyecto, los cambios, cursores, selecciones, estados y mensajes se comparten en tiempo real.

¿Cómo exporto mi diagrama?

Use Exportar JSON para una copia propia del diagramador o Exportar XMI para XMI 2.1. Para código, use Exportar backend.

¿Qué formatos XMI se pueden importar?

La aplicación acepta archivos .xmi y .xml, reconoce XMI 2.1 y archivos XMI 1.x de Enterprise Architect. La exportación genera XMI 2.1.

¿El boceto crea el proyecto inmediatamente?

No. Primero se muestra un resumen de lo interpretado; el proyecto se crea al presionar Crear proyecto y abrirlo.

¿Qué hago si la IA interpreta mal mi comando?

Explique el nombre exacto o haga el cambio manualmente. Para una acción local del agente puede usar Deshacer. En el chat, descarte la propuesta durante la votación.

¿Puedo recuperar un diagrama anterior?

Sí. Abra Versiones, previsualice una versión y use Restaurar esta versión. Antes de restaurar se conserva una copia del estado actual.

¿Cómo se cancela una nota de voz?

Mientras mantiene presionado el micrófono, deslice hacia la izquierda o presione Esc; luego suelte.

¿Puedo renombrar o eliminar un proyecto desde la pantalla principal?

No. La interfaz actual permite crear y abrir proyectos, pero no muestra acciones para renombrarlos o eliminarlos. Cambiar Nombre del modelo dentro del editor no cambia la tarjeta del proyecto.

Glosario

Consulte los términos utilizados a lo largo de esta guía.

UML
lenguaje visual utilizado para representar la estructura de un sistema.
Clase
elemento que representa un tipo de objeto con atributos y operaciones.
Interfaz
contrato de operaciones que una clase puede realizar.
Clase abstracta
clase que sirve como base de otras y no se instancia directamente.
Atributo
dato o propiedad de una clase.
Operación
acción o método definido en una clase o interfaz.
Parámetro
dato que recibe una operación.
Relación
vínculo entre dos elementos del diagrama.
Multiplicidad
cantidad permitida de objetos en un extremo de una relación, por ejemplo 1, 0..1 o 0..*.
Navegabilidad
indica desde qué extremo se puede recorrer una relación.
Clase de asociación
clase que guarda datos propios de una relación.
XMI
formato XML para intercambiar modelos UML entre herramientas.
JSON
formato utilizado por la copia completa propia del diagramador.
Spring Boot
estructura de backend Java que la aplicación puede generar y descargar.
Boceto
fotografía o captura de un diagrama que la aplicación intenta reconstruir.
IA
asistente que puede responder preguntas y proponer o ejecutar operaciones sobre el diagrama.
Proyecto compartido
proyecto de otra persona al que se accede mediante una invitación aceptada.
UUID
identificador único de la cuenta utilizado para enviar invitaciones.
Sala
sesión en tiempo real formada por las personas que tienen abierto el mismo proyecto.
Versión
copia guardada del diagrama en un momento determinado.
Cambio provisional
modificación propuesta por la IA que todavía espera la decisión de la sala.
